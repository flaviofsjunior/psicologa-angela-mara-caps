# Psicóloga Angela Mara · CAPS e cuidado em rede

Site estático e responsivo, em português, com conteúdo educativo sobre os Centros de Atenção Psicossocial (CAPS) e ferramentas interativas de organização do fluxo.

## Como abrir

Abra `index.html` no navegador. Para testar os recursos de cópia, sirva a pasta com um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicação no GitHub Pages

Publique os arquivos desta pasta em um repositório GitHub. Nas configurações do repositório, em **Pages**, escolha **Deploy from a branch**, ramo `main` e pasta `/ (root)`.
